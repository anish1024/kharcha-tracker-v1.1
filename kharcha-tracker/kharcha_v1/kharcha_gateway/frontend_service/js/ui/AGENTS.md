# AGENT.md — Kharcha Tracker ui modules

## `js/ui/toast.js`

- Exports `showToast(message, kind)`
- Renders into `#toast`
- Owns the toast timer
- Import: `import { showToast } from "../ui/toast.js"`

## `js/ui/forms.js`

- Exports `setError(errEl, msg)` and `setBusy(btn, on, busyText)`
- Forwards error messages into per-form error elements
- Forwards busy state + label text to submit/busy buttons
- Import: `import { setError, setBusy } from "../ui/forms.js"`

## `js/ui/modal.js`

- Exports `openModal(html, title)`, `closeModal()`
- Escapes overlay click-to-close and Escape handling into `#modal-root`
- Receives HTML generated by feature render functions
- Import: `import { openModal, closeModal } from "../ui/modal.js"`

## Cross-module notes

- These modules must not import feature modules (one-way dependency).
- Feature modules should never define their own toast/form/modal logic.
